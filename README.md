## What I've Learned

This program was structured into several key modules, each focusing on a different aspect of web development.

### ALG101: Algorithmic Thinking and Problem Solving

-   **Core Concepts:** Developed foundational problem-solving skills using JavaScript.
-   **Projects & Exercises:**
    -   Implemented classic algorithms like finding prime numbers and calculating square roots.
    -   Solved logic puzzles such as digit manipulation and string processing.
    -   Practiced algorithmic thinking through various coding challenges on platforms like LIOJ.

### NET101 & JS101/JS201: Web Fundamentals and Advanced JavaScript

-   **Core Concepts:** Gained a deep understanding of how the web works, including HTTP/HTTPS protocols, request/response cycles, and the core principles of JavaScript.
--   **Key Skills:**
    -   **JavaScript Fundamentals:** Variables, data types, operators, control flow.
    -   **Advanced Topics:** Closures, scope, hoisting, prototypes, inheritance, and ES6+ features (classes, arrow functions, promises).
    -   **Networking:** Understanding of network protocols and making HTTP requests.

### FE101/FE102/FE201: Front-End Development

-   **Core Concepts:** Built a strong foundation in creating responsive, interactive, and user-friendly interfaces.
-   **Key Skills:**
    -   **HTML5 & CSS3:** Semantic HTML, advanced selectors, Flexbox, and Grid.
    -   **JavaScript (DOM):** Manipulating the DOM, handling events, and creating dynamic web pages.
    -   **AJAX & APIs:** Fetching and displaying data from external APIs asynchronously.
    -   **Modern Tools:**
        -   **Sass:** Writing more maintainable and modular CSS.
        -   **Webpack & Babel:** Bundling assets and transpiling modern JavaScript for browser compatibility.
        -   **Bootstrap:** Rapidly building responsive layouts.

### BE201: Back-End Development with Node.js

-   **Core Concepts:** Learned to build server-side applications, manage databases, and create robust APIs.
-   **Key Skills:**
    -   **Node.js & Express:** Setting up servers, handling routes, and managing middleware.
    -   **MVC Architecture:** Structuring applications using the Model-View-Controller pattern.
    -   **Templating:** Using EJS to render dynamic HTML on the server.
    -   **Database Management:**
        -   **SQL:** Writing queries to interact with relational databases.
        -   **Database Design:** Creating and managing database schemas.
    -   **Project:** Built a complete To-Do list application with user authentication.

### FE302: Modern Front-End with React

-   **Core Concepts:** Mastered the component-based architecture of React to build complex, single-page applications (SPAs).
-   **Key Skills:**
    -   **React Fundamentals:** Components (class and functional), JSX, props, and state.
    -   **React Hooks:** `useState`, `useEffect`, `useContext`, and custom hooks for managing component logic.
    -   **API Integration:** Fetching and displaying data from APIs within a React application.
-   **Projects:**
    -   **Weather App:** A dynamic application that fetches and displays weather data from a third-party API.
    -   **Message Board:** A full-featured message board with user interactions.
